# Casamento Daniela & Pedro — Photobooth NFC

Protótipo estático para GitHub Pages. Permite abrir a câmara do telemóvel, alternar entre frontal e traseira, tirar fotografias individuais, escolher entre duas molduras ou sem moldura e descarregar as versões original e personalizada.

## Publicação
Em **Settings → Pages**, selecionar **Deploy from a branch**, branch **main**, pasta **/ (root)**.

Endereço previsto: https://grimperes.github.io/Casamento-DanielaPedro/

## Notas
- A câmara exige HTTPS e autorização do utilizador.
- Nesta fase, as fotografias não são enviadas nem guardadas na cloud.
- O Supabase, a moderação e o slideshow serão implementados posteriormente.
- Não incluir chaves privadas no código público.
